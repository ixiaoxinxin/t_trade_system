## 目标

训练第一个方向分类模型，输出次日上涨概率和方向置信度。模型只辅助排序和观察，不替代规则等级。

## 固定持仓样本池

每天固定刷新并置顶：

| 股票代码 | 股票名称 |
|---|---|
| 002192 | 融捷股份 |
| 600096 | 云天化 |
| 002213 | 大为股份 |
| 000933 | 神火股份 |
| 002466 | 天齐锂业 |

规则：

- 卖点信号固定置顶。
- 午盘验证固定置顶。
- 次日复盘固定置顶。
- 页面单独展示固定持仓监控表，一票一行。
- 可单独刷新固定持仓买点和卖点。
- 行情为空时显示待刷新，不隐藏。
- 行情待刷新行不进入有效训练标签。
- 固定持仓分时数据用于补充模型训练特征。

## 模型任务

- 使用 LightGBM 二分类模型。
- 标签为 `direction_up_close`，即次日收盘是否上涨。
- 建立训练、验证、测试脚本。
- 输出 AUC、PR-AUC、准确率、分市场环境命中率、分行业命中率。
- 将预测结果写入 SQLite。

## 页面变化

- 页面从大工作区改成独立一级 Tab，减少来回找入口。
- 一级 Tab 为：明日计划、固定持仓、交易记录、午盘验证、模型训练、模型预测。
- 固定持仓单独成 Tab，展示五只持仓的买点、卖点、午盘、次日状态，并提供持仓行情/买卖点刷新按钮。
- 交易记录单独成 Tab，只记录真实日内T/隔日T，不再和系统复盘混放。
- 午盘验证单独成 Tab，专门看上午结构和下午操作建议。
- 模型训练单独成 Tab，看样本质量和模型评估报告。
- 模型预测单独成 Tab，看次日上涨概率排序。
- 明日计划、卖点、午盘、次日复盘展示次日上涨概率和方向置信度。
- 人工复盘入口继续下线，真实复盘数据从交易记录沉淀。

## 输出

- `data/models/direction_model_v2.6.joblib`
- `data/models/direction_model_v2.6_features.json`
- `output/model_evaluation_v2.6.md`
- `output/model_predictions_v2.6.csv`
- SQLite 表：`model_training_runs`、`model_prediction_results`

```bash
python main.py holdings-refresh

python main.py model-train
python main.py model-predict
python main.py model-predict --stock-code 002466
```

## 验收

- 五只固定持仓在卖点、午盘、次日复盘中固定出现。
- 页面存在独立的固定持仓、交易记录、午盘验证、模型训练、模型预测 Tab。
- 单只股票可输出次日上涨概率。
- 全市场候选可按上涨概率排序。
- 模型评估报告可复现。
