# v3.0 封板五步开发计划

## 目标

把 v2.6-v2.9 已完成的概率、校准和回顾能力，融合成最终操作。

## 五个 Commit

| 顺序 | Commit | 目标 |
|---:|---|---|
| 1 | `feat: add v3.0 decision fusion engine` | 生成融合评分和最终操作 |
| 2 | `feat: integrate final decision into trade plan` | 交易计划和固定持仓展示最终操作 |
| 3 | `feat: add single stock decision workspace` | 单票查询，不覆盖全量预测 |
| 4 | `feat: improve intraday path and range review` | 路径标签和区间回顾 |
| 5 | `chore: seal v3.0 workflow and quality gates` | 封板文档、质量门禁、验收流 |

## 验收主线

```text
生成明日计划 -> 生成最终决策 -> 看固定持仓 -> 记录交易 -> 次日复盘 -> 预测回顾 -> 模型评分
```

## 最小验收命令

```bash
python main.py decision-fusion
python main.py prediction-review
python -m unittest discover -s tests
```
