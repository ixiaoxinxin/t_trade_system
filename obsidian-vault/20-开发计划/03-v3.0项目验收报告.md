# v3.0 项目验收报告

更新日期：2026-07-20

## 验收结论

v3.0 已达到“规则评分 + 模型概率 + 风控融合 + 页面闭环”的封板目标，可以作为后续 v4.0 开发基线。

当前主流程已经形成：

```text
生成明日计划 -> 查看最终操作 -> 固定持仓处理 -> 单票决策 -> 交易记录 -> 次日复盘 -> 保存训练数据 -> 模型训练/预测
```

## 已完成能力

- 统一入口和页面工作流。
- SQLite 样本库、特征、标签、预测日志和真实交易记录。
- 固定持仓单独跟踪：融捷股份、云天化、大为股份、神火股份、天齐锂业。
- 日内T/隔日T真实交易记录，按招行证券万2.5计算手续费和到手利润。
- 方向模型、收益目标概率、概率校准、轻量解释、预测回顾。
- 规则等级、模型概率、板块状态、市场环境和固定持仓状态融合成最终操作。
- 页面标题和模型预测页面已去版本噪音。
