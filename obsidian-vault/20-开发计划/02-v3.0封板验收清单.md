# v3.0 封板验收清单

工程文档：`docs/v3.0_acceptance_checklist.md`

## 命令

```bash
python main.py decision-fusion
python main.py plan
python main.py single-stock --stock-code 002466
python main.py prediction-review
python -m unittest discover -s tests
```

## 页面

- 明日计划：看 v3.0 最终操作。
- 固定持仓：看五只固定持仓的最终操作、买点和卖点。
- 单票决策：输入 `002466` 看天齐锂业完整决策链。
- 交易记录：记录真实日内T/隔日T。
- 模型预测：看概率、校准、解释和评分卡。

## 封板标准

- 能从最终操作直接知道明天看哪几只。
- 单票工作台不覆盖全市场预测。
- 路径和区间回顾能沉淀到预测回顾。
- 全量单元测试通过。
