# v3.0 封板差距分析与五步计划

## 核心结论

当前系统已经具备：

- 规则等级。
- 板块资金过滤。
- 固定持仓跟踪。
- SQLite 样本库。
- 真实交易记录。
- 次日上涨概率。
- +1% / +2% / 止损概率。
- 概率校准。
- 预测回顾和模型评分。

离成熟决策系统还差最后一步：把这些信息融合成“最终操作”。

## 当前最大差距

| 能力 | 当前状态 | 还差什么 |
|---|---|---|
| 最终操作 | 有交易计划和卖点信号 | 缺规则 + 概率 + 风控融合 |
| 单票判断 | CLI 可单票预测 | 页面缺单票工作台 |
| 固定持仓 | 已单独展示 | 需要最终处理建议 |
| 概率模型 | 已有 v2.6-v2.8 | 样本少，需降权使用 |
| 预测回顾 | 已有 v2.9 | 需要反哺融合权重 |
| 路径/区间 | 有事后标签雏形 | 需分钟路径和区间重合度 |

## 五个 Commit 计划

### 1. 融合决策引擎

`feat: add v3.0 decision fusion engine`

- 新增 `decision_fusion.py`。
- 融合规则等级、模型概率、校准概率、板块资金、市场环境、模型评分。
- 输出最终操作、融合评分、操作解释。
- 已实现入口：`python main.py decision-fusion`。
- 已实现输出：`output/final_decision_v3.0.csv`、`output/final_decision_v3.0.md`、SQLite 表 `final_decision_v3`。

### 2. 交易计划接入最终操作

`feat: integrate final decision into trade plan`

- 明日计划展示最终操作。
- 固定持仓展示持仓处理建议。
- 页面展示规则依据和模型依据。
- 已实现：`daily_plan.md` 新增 v3.0 最终操作、明日重点、固定持仓处理。
- 已实现：页面明日计划 Tab 可刷新并查看最终决策，固定持仓 Tab 可直接查看最终操作。

### 3. 单票工作台

`feat: add single stock decision workspace`

- 页面支持股票搜索。
- 单票查询不覆盖全量预测。
- 单票展示完整决策链。
- 已实现：`python main.py single-stock --stock-code 002466` 可生成天齐锂业单票报告。
- 已实现：页面新增 `单票决策` Tab，查询结果单独写入 `single_stock_decision` 文件。

### 4. 路径标签与区间回顾

`feat: improve intraday path and range review`

- 增强分钟路径标签。
- 增加区间覆盖率和区间重合度。
- 无分钟数据时明确不可判断。
- 已实现：预测回顾 CSV 增加路径标签、计划区间、覆盖率、重合度、低吸可成交标记。
- 已实现：预测回顾报告增加路径分布和区间质量指标。

### 5. v3.0 封板体验与质量门禁

`chore: seal v3.0 workflow and quality gates`

- 更新 README、工作流、知识库。

## 封板验收

1. 明日计划能看到最终操作。
2. 固定持仓能看到买点、卖点、概率和最终处理建议。
3. 单票查询能回答“这只票现在怎么看”。
4. 次日复盘能解释模型预测准不准。
5. 交易记录能继续沉淀真实执行结果。
