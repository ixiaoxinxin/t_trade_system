# 日常操作工作流

这篇文档只讲真实使用，不讲代码。

现在页面分成四个工作区：

- 今日操作台：今天能不能做、持仓怎么管、真实交易怎么记。
- 明日计划：收盘后看明天关注哪几只。
- 复盘验证：次日验证系统计划，也看真实交易结果。
- 数据与模型：把数据沉淀到 SQLite，给后续模型训练用。

最重要的一句话：

> 收盘生成明日计划，盘中记录交易和看卖点，次日做复盘，最后保存训练数据。

## 1. 日常按钮怎么用

### 生成明日计划

收盘后点。

它会自动跑完：

1. 市场环境。
2. 候选扫描。
3. 尾盘确认。
4. 交易计划。

点完以后去「明日计划」看 A/B 候选。

### 更新卖点信号

有持仓时点。

它不是选新票的，是判断手里的票要继续拿、减仓、止盈还是止损。

### 午盘验证

11:20 以后点。

用来看昨天计划里的票上午走得怎么样，下午还值不值得盯。

### 次日复盘

第二天收盘后点。

它验证昨天计划是否触达低吸区间、是否到 +1% / +2%、是否触发 -2% 止损。

### 保存训练数据

次日复盘后点。

它把候选、计划、验证、真实交易记录、行情缓存沉淀到 SQLite，给后续模型训练用。

### 高级工具

平时不用频繁点。

- 单独刷新市场环境：只想看大盘状态时使用。
- 刷新固定持仓行情：只刷新融捷股份、云天化、大为股份、神火股份、天齐锂业的日线和分钟数据。
- 刷新持仓买卖点：只刷新五只固定持仓的买点区间、买点状态和卖点信号。
- 迁移数据库：页面数据没刷新，或手动改了 output 文件后使用。

## 2. 四个工作区怎么看

### 今日操作台

这里处理今天正在发生的事。

你主要看：

- 市场环境：今天适不适合隔夜。
- 板块资金方向：钱在往哪里流。
- 固定持仓监控：五只持仓单独成表，集中看买点区间、卖点信号、午盘、次日复盘和模型概率。
- 交易记录：真实买卖随手记。
- 持仓卖点：有票时看是否要卖。
- 午盘验证：中午看上午结构。

真实操作顺序：

```text
先看市场 -> 看固定持仓 -> 有交易就记交易 -> 有持仓就看卖点 -> 中午看午盘验证
```

### 明日计划

这里看明天要关注什么。

只重点看 A/B 候选：

- 市场是否允许隔夜。
- 个股是否 A/B。
- 板块状态是否可靠。
- 风险等级是否过高。
- 交易计划里的低吸区间是否合理。

如果候选太多，就只保留自己明天真的愿意盯的 1-3 只。

### 复盘验证

这里看结果。

它分两类：

- 系统次日验证：系统昨天的计划理论上有没有成功。
- 真实交易复盘：你实际有没有买卖、有没有赚到钱、是否按计划执行。

这两个不要混在一起。

系统验证回答：

```text
这套规则昨天判断得对不对？
```

交易记录回答：

```text
我真实执行后赚没赚到钱？
```

以后个性化模型要同时看这两件事。

### 数据与模型

这里看数据地基是否健康。

重点看：

- 样本数。
- 标签覆盖率。
- 特征覆盖率。
- LLM 辅助标签成本。
- v2.6 模型评估报告。
- 次日上涨概率排序。

如果标签覆盖率低，说明很多候选还没有完成次日复盘。

## 3. 最贴近真实操作的一天

### 盘前或上午

打开「今日操作台」。

先看市场环境。

如果是情绪冰点、系统风险、是否隔夜为否，就降低预期。可以观察，但不要强行做隔夜。

### 盘中有交易

直接在「今日操作台」里填交易记录。

只要先买了但还没卖，卖出价可以先空着，状态就是未闭环。

如果盘中涨起来，点「更新卖点信号」，看系统建议是继续拿、减仓、止盈还是止损。

### 中午

11:20 以后点「午盘验证」。

它主要帮你判断上午结构：

- 上午强，下午可以继续观察。
- 上午冲高回落，下午要警惕。
- 上午完全不符合预期，可以降低关注。

### 收盘后

点「生成明日计划」。

然后进入「明日计划」，只看 A/B 候选和交易计划。

### 第二天收盘后

点「次日复盘」。

然后进入「复盘验证」看系统计划是否有效。

如果你当天做了真实交易，把「交易记录」补完整：卖出价、数量、备注。

最后点「保存训练数据」。

如果要更新模型，进入「数据与模型」：

1. 点「训练方向模型」。
2. 点「生成模型预测」。
3. 回到「明日计划」或「今日操作台」看次日上涨概率。

## 4. 推荐固定节奏

### 每天必做

1. 收盘后点「生成明日计划」。
2. 第二天收盘后点「次日复盘」。
3. 有真实交易就填「交易记录」。
4. 次日复盘后点「保存训练数据」。
5. 数据更新后点「训练方向模型」和「生成模型预测」。

### 盘中按需做

- 有持仓：点「更新卖点信号」。
- 中午想看上午结构：点「午盘验证」。
- 固定持仓数据缺失：点「刷新固定持仓行情」。
- 只想看持仓买卖点：点「刷新持仓买卖点」。

### 每周做一次

- 看「复盘验证」里的系统验证结果。
- 看「复盘验证」里的真实交易记录。
- 看「因子表现」。
- 看「数据与模型」里的标签覆盖率和人工复核队列。

## 5. 最简单的使用口诀

一句话版本：

> 收盘选明天，盘中管卖点，交易随手记，次日做复盘，最后进数据集。

按钮顺序版本：

```text
生成明日计划 -> 明日计划
有持仓 -> 今日操作台 -> 更新卖点信号 / 午盘验证 / 交易记录
第二天 -> 次日复盘 -> 复盘验证 -> 保存训练数据
有新训练数据 -> 数据与模型 -> 训练方向模型 -> 生成模型预测
每周 -> 复盘验证 -> 因子表现 + 真实交易记录
```

## 6. 容易混的地方

### 生成明日计划和保存训练数据不是一回事

生成明日计划是为了“明天看什么”。

保存训练数据是为了“把已经发生的预测和结果存起来，给以后训练模型用”。

### 更新卖点信号和次日复盘不是一回事

更新卖点信号是盘中决策辅助。

次日复盘是事后验证和打标签。

### 交易记录和系统验证不是一回事

系统验证记录的是“系统计划理论上有没有成功”。

交易记录记录的是“你实际有没有赚到钱”。

后面个性化模型要同时看这两件事。

### 人工复盘入口为什么删除

因为人工复盘很容易和交易记录重复。

以后真实复盘只从交易记录出发：你买了什么、卖了什么、赚亏多少、是否按计划执行。

## 7. 每天真正要盯的数字

首页中间那些数字可以这样理解：

- 市场环境：今天大背景。
- 是否隔夜：今天能不能做隔夜。
- A/B候选：明天值得认真看的票数量。
- 卖点信号：当前有多少持仓触发卖点判断。
- 午盘验证：有多少计划已经完成上午验证。
- 成功率：当前历史验证的大致成功率。
- 交易记录：你真实记录了多少笔交易。
- 已闭环：已经买卖闭环、可以用于真实复盘的交易数量。

如果只想快速判断今天要不要认真看盘，优先看：

```text
市场环境 -> 是否隔夜 -> A/B候选
```

如果已经有持仓，优先看：

```text
更新卖点信号 -> 交易记录 -> 午盘验证
```

如果在做系统迭代，优先看：

```text
次日复盘 -> 因子表现 -> 数据与模型
```
