# 模型训练与模型预测工作流

模型相关页面分成两个 Tab：

- 模型训练：看历史数据够不够、模型训练得怎么样。
- 模型预测：把训练结果用到今天的候选排序里。

日常仍然先看「明日计划」里的最终操作，再看「单票决策」里的依据。

## 为什么方向置信度会一样

方向置信度的计算逻辑是：

```text
方向置信度 = |次日上涨概率 - 0.5| * 2
```

如果所有股票的次日上涨概率都一样，方向置信度也会一样。

常见原因：

- 样本太少。
- 标签分布太单一。
- 可用特征不足。
- 方向模型回退成整体基准概率。

这时不要把它当作强个股信号，只能作为当前样本下的整体风险提示。

## 模型训练怎么用

真实顺序：

```text
次日复盘完成 -> 保存训练数据 -> 训练方向模型 -> 训练收益目标概率模型 -> 生成校准与解释 -> 生成预测回顾
```

重点看：

- 样本数。
- 特征快照数。
- 标签数。
- 方向模型评估报告。
- 收益目标概率评估报告。
- 概率校准和预测回顾。

只有保存了新的训练数据后，再训练才有实际意义。

## 模型预测怎么用

真实顺序：

```text
生成明日计划 -> 生成方向预测 -> 生成收益目标概率 -> 回到明日计划看最终操作
```

主要看：

- 次日上涨概率排序。
- 达到 +1% / +2% 概率。
- 止损概率。
- 校准后概率。
- 单票多空因素。
- 模型评分卡。

预测结果会回流到「明日计划」「固定持仓」「单票决策」和「预测回顾」。

## 最简单理解

```text
模型训练负责学习过去
模型预测负责给今天排序
最终操作负责告诉你明天怎么处理
交易记录负责沉淀你的真实执行
```

## 什么时候先别信模型

- 所有股票概率都一样。
- 样本数很少。
- 最近市场环境突变。
- 方向模型和规则评分明显冲突。
- 固定持仓触发明确卖点或风控。

优先级：

```text
风控 -> 卖点信号 -> 最终操作 -> 规则等级 -> 模型概率
```
