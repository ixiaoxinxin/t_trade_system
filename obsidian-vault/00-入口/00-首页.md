## 当前版本重点

- v2.0 已完成工程基线：版本统一、入口规范、依赖修复、字段契约、运行追踪和次日验证口径优化。
- v2.4-v3.0 的路线是从规则系统升级为成熟决策系统：规则策略评分 + 机器学习概率 + 预测回顾 + 模型解释。
- v2.5 已单独拆出 [[03-v2.5训练数据集与标签系统]]，重点是样本库、标签口径、真实交易记录、LLM 辅助标注和 API 成本控制。
- v2.5.1-v2.5.2 合并做页面工作流简化和数据质量优化，人工复盘入口下线，真实复盘统一从交易记录沉淀。
- v2.6 开始训练 [[05-v2.6次日涨跌方向模型]]，并新增固定持仓样本池：融捷股份、云天化、大为股份、神火股份、天齐锂业。
- 保持系统定位清晰：本项目是个人交易辅助与复盘工具，不做自动下单。

## 日常使用方式

1. 需求变化记录到 `10-需求`。
2. 开发拆解和排期记录到 `20-开发计划`。
3. 每次运行和问题定位记录到 `30-运行记录`。
4. 交易案例、因子复盘和规则修正记录到 `40-复盘沉淀`。
