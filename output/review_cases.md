| 交易类型 | 板块风险失败案例 |
| 买入价 | 未记录 |
| 卖出价 | 未卖出 |
| 数量 | 神火300股 / 兴业银锡200股 |
| 实际盈亏 | 浮亏 |
| 市场环境 | 弱市 |

| 系统结构 | 板块风险暴露 |
| 尾盘特征 | 个股买入时未充分过滤板块强弱 |
| 问题归因 | 两只票同属有色，相当于集中押注同一弱板块；早盘板块重锤，个股同时下跌。 |
| 优化规则 | 新增板块强度因子；同板块最多持有1只；高波动板块弱市降仓或禁买。 |
| 沉淀因子 | 板块强弱 > 个股局部结构；资源股高Beta，弱市风险更高。 |
| 系统结论 | 系统必须加入板块过滤，否则会出现个股选择正确但方向错误。 |

## 三、当前系统修正方向

| 问题 | 修正方向 |
|---|---|
| 卖点偏慢 | 用 sell_signal_engine.py 约束止盈、减仓、清仓 |
| 浮盈回吐 | 高点回撤超过 1.5% 触发减仓 |
| 弱市恋战 | 偏弱/系统风险环境下达到 2% 优先兑现 |
| 板块集中暴露 | 新增板块强度因子，同板块限制持仓 |
| 高Beta板块暴跌 | 有色、资源类弱市自动降权 |
