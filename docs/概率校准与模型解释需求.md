## 1. 目标

v2.8 让 v2.7 的收益目标概率更可用：

- 输出校准前后 Brier Score。
- 输出概率分桶校准曲线。
- 输出校准后的 +1%、+2%、止损概率。
- 输出单票多空因素摘要。

本版本先实现轻量可复现解释，不强依赖 SHAP。样本量和依赖稳定后，再升级为真正 Tree SHAP。

## 2. 输入

- `output/profit_probabilities_v2.7.csv`
- SQLite `label_snapshot`
- `data/models/profit_probability_model_v2.7.pkl`
- `feature_snapshot`

## 3. 校准逻辑

- 按 20% 为一个概率桶：0-20%、20-40%、40-60%、60-80%、80-100%。
- 每个目标分别统计：
  - 平均预测概率。
  - 实际发生率。
  - 样本数。
  - 原始 Brier Score。
  - 校准后 Brier Score。
- 校准概率使用对应概率桶的实际发生率。
- 样本为空时不伪造校准曲线。

## 4. 解释逻辑

- 优先读取模型特征重要性。
- 单票解释使用“特征重要性 × 单票特征相对中位数偏离”生成偏多/偏空因素。
- 如果模型为基准概率模型或没有稳定特征重要性，解释结果明确标记“样本不足或基准模型”。
- 不把模型解释覆盖规则解释，二者并列展示。

## 5. 输出

- `output/probability_calibration_v2.8.md`
- `output/calibrated_probabilities_v2.8.csv`
- `output/model_explanations_v2.8.csv`
- `data/models/probability_calibration_v2.8.json`
- SQLite 表：`probability_calibration_curves`
- SQLite 表：`model_explanations`

## 6. 页面

保持页面结构不变：

- 「模型训练」新增生成校准与解释按钮。
- 「模型训练」展示 v2.8 校准报告。
- 「模型预测」展示校准后概率和单票多空因素。

## 7. CLI

```bash
python main.py calibrate-explain
```

## 8. 验收标准

- `python main.py calibrate-explain` 可生成校准报告、校准预测和解释 CSV。
- SQLite 中存在 `probability_calibration_curves` 和 `model_explanations`。
- 报告可看到每个目标的 Brier Score 和概率桶实际发生率。
- 页面可查看校准后概率与单票多空因素。
- 样本不足时解释明确降级，不伪造 SHAP。

## 9. 风险

- 当前样本量少，校准曲线容易波动。
- 概率桶校准是第一版，后续可引入 Platt Scaling 或 Isotonic Regression。
- SHAP 解释需要更多样本和依赖稳定后再接入。
