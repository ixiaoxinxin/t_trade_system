## 4. v3.0 封板判断

本版本封板目标不是提高模型胜率，而是把分散模块串成可执行闭环：

- 规则决定能不能做。
- 模型概率决定值不值得关注。
- 板块和市场环境决定是否降级。
- 最终操作直接告诉用户看哪只、怎么处理。
- 单票工作台用于临场复核。
- 真实交易记录用于后续个性化模型。

## 5. 已知限制

- 当前样本量仍少，模型概率只作为辅助，不作为单独买卖依据。
- 路径先后判断当前优先使用标签表和次日高低幅；分钟事件序列充足后再升级为更精确版本。
- 固定持仓如缺少行业映射，会显示板块未知，但仍可进行买点、卖点和概率跟踪。
