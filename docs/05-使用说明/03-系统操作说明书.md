## 1. 最重要的使用原则

实盘时只先看一句话：

```text
最终操作 + 股票名称 + 简短原因
```

分数、概率、模型解释都只是明细，不是第一眼要看的东西。

## 2. 页面用途

| 页面 | 用途 |
|---|---|
| 明日计划 | 看明天关注什么、怎么处理 |
| 固定持仓 | 看手里已有股票要持有、减仓、止盈还是止损 |
| 系统次日验证 | 看昨天系统计划准不准，不直接指导今天买卖 |
| 交易记录 | 记录真实买卖，用于个性化模型 |
| 模型预测 | 看模型是否有区分度，概率一致时只作观察 |

## 3. 固定持仓话术

| 操作 | 含义 |
|---|---|
| 继续持有 | 暂未触发卖点，可以继续观察 |
| 减仓 | 风险升高，先降低仓位 |
| 止盈 | 收益已到，优先落袋 |
| 清仓 | 卖点触发，先退出 |
| 止损 | 跌破风控，立即退出 |

## 4. 候选池话术

| 操作 | 含义 |
|---|---|
| 优先低吸 | 可以重点看，但只等计划买点 |
| 小仓观察 | 可以看，不追高 |
| 只观察 | 条件不够，先不买 |
| 放弃 | 风险不划算，不看 |

## 5. 系统次日验证怎么用

系统次日验证不是今天买卖信号。

它只回答：

- 昨天的计划有没有给买点。
- 给买点后有没有达到目标。
- 有没有先触发止损。
- 哪些规则应该保留或降权。

验证结果会进入数据集，给后续模型训练和规则优化使用。

## 6. 模型概率一致怎么办

如果方向预测、达到 1% 概率、达到 2% 概率、止损概率都差不多，说明模型当前没有形成有效区分。

这时：

- 不用模型概率排序。
- 不根据概率做买卖。
- 优先看规则等级、卖点信号、市场环境和最终操作。
