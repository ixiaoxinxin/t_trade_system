这篇文档只讲页面怎么用。

模型相关页面分成两个 Tab：

- 模型训练：回答“我的历史数据够不够、模型训练得怎么样”。
- 模型预测：回答“今天这些候选里，模型觉得谁更值得排前面”。

模型不是最终裁判。日常操作仍然先看「明日计划」里的最终操作，再看「单票决策」里的依据。

## 1. 为什么方向置信度会一样

方向置信度的计算逻辑是：

```text
方向置信度 = |次日上涨概率 - 0.5| * 2
```

如果所有股票的次日上涨概率都一样，方向置信度也会一样。

这通常说明模型处在早期状态：

- 样本太少。
- 标签分布太单一，比如大部分样本都是失败或都是成功。
- 可用特征还不足，模型没学出不同股票之间的差异。
- 方向模型回退成了整体基准概率。

这种情况下，不要把它当作强信号。它只说明“当前样本下整体胜率偏向哪里”，不能说明“某一只股票特别强”。

## 2. 模型训练 Tab 怎么用

模型训练 Tab 做四件事：

1. 看数据集质量。
2. 训练方向模型。
3. 训练收益目标概率模型。
4. 生成校准、解释和预测回顾。

真实操作顺序：

```text
次日复盘完成 -> 保存训练数据 -> 训练方向模型 -> 训练收益目标概率模型 -> 生成校准与解释 -> 生成预测回顾
```

### 什么时候点

每天不一定都要训练。只有当你做了次日复盘、补了交易记录、保存了新的训练数据之后，再训练才有意义。

### 点完看什么

先看三类数字：

- 样本：已经沉淀了多少个候选样本。
- 特征快照：每个样本对应的行情和规则因子是否足够。
- 标签：有没有真实结果可以训练。

再看评估报告：

- 方向模型评估报告：上涨/下跌方向有没有基本区分度。
- 收益目标概率评估报告：达到 +1%、+2%、触发止损的概率是否稳定。
- 概率校准与解释报告：模型概率有没有明显偏乐观或偏悲观。
- 预测回顾与模型评分报告：过去预测和真实结果对上后的表现。

## 3. 模型预测 Tab 怎么用

模型预测 Tab 是训练后的使用入口。

真实操作顺序：

```text
生成明日计划 -> 生成方向预测 -> 生成收益目标概率 -> 回到明日计划看最终操作
```

它会输出几类表：

- 次日上涨概率排序：模型认为收盘上涨概率较高的候选。
- 收益目标概率排序：达到 +1%、+2% 和触发止损的概率。
- 校准后概率：经过历史回顾修正后的概率。
- 单票多空因素：模型当前能解释出的偏多和偏空依据。
- 模型评分卡：模型过去在不同市场和行业里的表现。

## 4. 预测结果在哪里体现

预测结果会回流到这些地方：

- 明日计划：和规则等级、市场环境、板块状态一起生成最终操作。
- 固定持仓：固定持仓会置顶显示上涨概率、收益目标概率和卖点信号。
- 单票决策：输入一只股票后，看这只票的规则、模型、买卖点和最终建议。
- 预测回顾：第二天复盘后，验证模型昨天预测得准不准。

最简单的理解：

```text
模型训练负责学习过去
模型预测负责给今天排序
最终操作负责告诉你明天怎么处理
交易记录负责沉淀你的真实执行
```

## 5. 什么时候先别信模型

出现以下情况时，模型只做参考：

- 所有股票概率都一样。
- 样本数很少。
- 最近市场环境突变。
- 方向模型和规则评分明显冲突。
- 固定持仓触发了明确卖点或风控。

这时优先级是：

```text
风控 > 卖点信号 > 最终操作 > 规则等级 > 模型概率
```
