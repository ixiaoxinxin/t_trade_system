# PushPlus移动端推送优化需求

## 图谱关系

上游：[开盘支撑压力与T区间需求](./14-开盘支撑压力与T区间需求.md)
下游：[PushPlus移动端推送优化开发计划](../04-开发计划/09-PushPlus移动端推送优化开发计划.md)

## 背景

当前 PushPlus 推送使用 Markdown 表格。手机屏幕宽度有限，卖点信号表字段多，会被压缩成竖排文字，实盘时难以快速判断动作。

## 目标

把手机推送改成移动端卡片样式。手机端优先展示影响操作的字段，不再把完整大表格直接推送到 PushPlus。

## 范围

1. 卖点信号推送改为 HTML 卡片。
2. 开盘T区间生成后同步推送到手机。
3. 本地 Markdown 报告继续保留，方便电脑端查看完整明细。

## 卖点信号手机字段

每只股票一张卡片，优先展示：

1. 股票名称和股票代码。
2. 卖出信号。
3. 操作短句。
4. 卖出理由。
5. 当前价。
6. 当前涨幅。
7. 高点回撤。
8. 冲高保持率。
9. 均线状态。
10. 隔夜等级。

## 开盘T区间手机字段

每只股票一张卡片，优先展示：

1. 股票名称和股票代码。
2. 当前操作。
3. 买进区间。
4. 卖出区间。
5. 支撑位。
6. 压力位。
7. 当前价。
8. 集合竞价/开盘价。
9. AI辅助提示。
10. 实时行情时间。

## 验收

1. 手机打开 PushPlus 卖点信号时，不再出现横向大表格。
2. 卖点信号以卡片形式展示，每张卡片能直接看到动作和理由。
3. 开盘T区间生成后，可以收到手机推送。
4. 开盘T区间推送能直接看到买进区间、卖出区间、支撑位和压力位。
5. 本地 `output/sell_signal.md` 和 `output/opening_levels.md` 仍保留原报告。
