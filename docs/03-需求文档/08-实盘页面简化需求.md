## 1. 背景

v3.0 已经打通规则、模型、板块、市场和最终操作，但实盘使用时发现页面仍偏工程化：

- 表格字段太多。
- 固定持仓和普通候选混在一起。
- 模型概率数值高度一致，不能用于排序。
- 操作解释太长，不适合盘中快速阅读。
- 交易记录录入不够顺手，利润未扣印花税。

本次改动目标是把页面改成“实盘能看懂、能快速记录、能明确区分用途”的简化版本。

## 2. 改动目标

- 明日计划只服务“明天怎么做”。
- 系统次日验证独立成 Tab，只服务复盘和训练数据。
- 固定持仓和普通候选分区展示。
- 所有决策表优先展示影响操作的列。
- 模型概率无区分度时自动降级，不作为主表排序依据。
- 操作解释改成固定短话术。
- 交易记录支持股票名称优先输入、价格文本输入、利润扣印花税。
- 固定持仓盘中价格必须优先使用实时行情，不得用旧日线或旧分钟缓存冒充当前价。

## 3. 页面规则

### 3.1 表格列顺序

所有实盘表遵循：

```text
操作结论 -> 股票名称 -> 股票代码 -> 简短原因 -> 状态字段 -> 明细字段
```

主表原则上不超过 8-10 个核心列。

### 3.2 固定持仓和候选池分开

固定持仓回答：

```text
我手里的票现在怎么处理？
```

候选池回答：

```text
明天哪些票值得看？
```

两者不能只靠 1/0 字段区分，必须分区展示。

### 3.3 模型概率降级

当方向概率或收益目标概率基本一致时，页面显示：

```text
当前模型未形成有效区分，只作观察。
```

此时主表不展示大段概率字段，也不把模型概率作为强排序依据。

### 3.4 操作话术

固定持仓话术：

| 操作 | 页面短句 |
|---|---|
| 继续持有 | 继续持有：暂未触发卖点。 |
| 减仓 | 减仓：风险升高，先降仓位。 |
| 止盈 | 止盈：收益已到，先落袋。 |
| 清仓 | 清仓：卖点触发，先退出。 |
| 止损 | 止损：跌破风控，立即退出。 |

候选池话术：

| 操作 | 页面短句 |
|---|---|
| 优先低吸 | 优先低吸：只等计划买点。 |
| 小仓观察 | 小仓观察：可看，不追。 |
| 只观察 | 只观察：条件不够，先不买。 |
| 放弃 | 放弃：风险不划算。 |

系统验证话术：

| 验证结果 | 页面短句 |
|---|---|
| 计划有效 | 计划有效：给了买点，达到目标。 |
| 计划待优化 | 待优化：给了买点，但收益不足或风险先到。 |
| 未给买点 | 未给买点：计划没有成交机会。 |
| 数据不足 | 数据不足：今天不参与判断。 |

## 4. 交易记录改动

- 股票名称放在第一输入项。
- 系统根据股票名称反填股票代码。
- 股票代码仍可手动补充。
- 已保存记录支持选择后修改，保存修改时覆盖原记录。
- 买入价、卖出价改为文本框。
- 数量保留数字输入。
- 利润计算增加卖出印花税。
- 印花税只在卖出侧计算，默认 0.05%。
- 费用字段拆分为买入佣金、卖出佣金、卖出印花税、费用合计。
- 修改记录后自动重新计算佣金、印花税、到手利润和收益率。
- 股票名称无法匹配且股票代码为空时仍允许保存，股票代码保持空白，不允许自动保存为 `000000`。
- 修改记录区支持按交易日期、股票名称和交易类型筛选。
- 模型训练区支持生成今日模型与预测复盘报告，集中评价准确率、低吸可成交率、模型提升度和程序问题。

## 5. 实时行情改动

- 固定持仓买点/卖点表的 `当前价` 优先来自单票实时行情接口。
- 实时行情字段包括最新价、昨收、今高、今低、行情日期和行情时间。
- 卖点信号计算优先使用实时最新价、今高、今低和昨收。
- 固定持仓回补区间不再使用 MA5 上下 1%，统一使用 `昨收 × 0.98` 到 `昨收 × 0.99`。
- 分钟数据只作为分时均价、结构判断和兜底来源。
- 页面展示 `实时行情时间` 和 `实时状态`，用户可以确认价格是否为当天盘中数据。
- 页面展示 `买点依据`，明确说明回补区间来源。

## 6. 验收标准

- 页面存在独立「系统次日验证」Tab。
- 明日计划里固定持仓和候选池分开。
- A/B 候选表第一列是操作结论。
- 主表不再直接堆方向概率、收益目标概率、风险收益比。
- 模型概率一致时页面有降级提示。
- 交易记录可只输入股票名称并反填代码。
- 交易记录提交后可以修改并覆盖原记录。
- 交易记录利润计算扣除印花税。
- 单元测试覆盖佣金、印花税和到手利润。
- 单元测试覆盖交易记录修改和空代码保存。
- 北京时间交易时段刷新固定持仓后，`当前价` 与实时行情接口一致，并显示当天 `实时行情时间`。
- 固定持仓买点上下限与昨收一致：下限为昨收回撤 2%，上限为昨收回撤 1%。
- `calibrate-explain` 在校准样本为空时不报 SQLite 语法错误。
- `python main.py daily-report` 可生成 `output/daily_model_report.md`。
