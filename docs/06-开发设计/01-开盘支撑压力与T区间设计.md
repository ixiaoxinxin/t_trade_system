## 数据流

1. `get_stock_daily` 读取日线，取当前行情日期之前的最后一个交易日作为“前一交易日”。
2. `get_stock_realtime_quote` 读取实时行情，取“今开”作为集合竞价结束后的开盘价。
3. `get_stock_minute` 读取1分钟线，用第一根分钟线开盘价兜底集合竞价价，并计算前15分钟高低点。
4. `output/trade_records.csv` 读取历史T记录，计算个人胜率和平均收益。
5. `output/model_predictions_v2.6.csv` 与 `output/profit_probabilities_v2.7.csv` 读取模型概率。
6. 基础算法先输出区间，DeepSeek 只做短句解释。

## 区间算法

基础变量：

1. `previous_close`：前一交易日收盘价。
2. `previous_high`：前一交易日最高价。
3. `previous_low`：前一交易日最低价。
4. `auction_price`：集合竞价价或第一根分钟线开盘价。
5. `current_price`：实时最新价。
6. `ATR`：近14日日内真实波幅均值。

计算原则：

1. 支撑位以昨日低点、昨日中枢、ATR回撤和当前价折价共同约束。
2. 压力位以昨日高点、昨日中枢、ATR上沿和当前价溢价共同约束。
3. 买进区间围绕支撑位展开，避免追高。
4. 卖出区间围绕压力位展开，优先保证T收益。
5. 如果历史T平均收益为负，买进区间上沿小幅下修，防止惯性追高。

## AI辅助边界

1. AI不直接改写支撑位、压力位、买进区间和卖出区间。
2. AI只根据传入JSON生成不超过28个汉字的操作提示。
3. AI失败或未配置Key时，页面仍展示算法结果。
4. AI调用成本记录在 `output/opening_levels_api_usage.csv`。
