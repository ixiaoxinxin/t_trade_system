# v4.0 宏观开发计划

更新日期：2026-07-20

## 1. v4.0 总目标

v4.0 的目标是把 v3.0 的“能跑通”升级为“更可信、更贴近实盘、更个性化”。

核心方向：

```text
数据质量 -> 路径预测 -> 个性化校准 -> 研究评估 -> 决策驾驶舱
```

v4.0 先分五个子版本推进。每个子版本开工前再单独写详细需求、字段设计、验收命令和测试方案。

## 2. v4.0 与示范系统的差距定位

示范系统的成熟形态是：

- 先判断明天涨跌。
- 再判断怎么走。
- 再判断涨跌区间。
- 再判断风险收益是否划算。
- 最后给出可执行操作。
- 第二天复盘预测是否准确。

v3.0 已完成第一层和最后一层的雏形：

- 已能输出规则等级、方向概率、收益目标概率、止损概率、板块状态、市场环境和最终操作。
- 已能记录预测并做回顾。

v4.0 要补齐中间最难的部分：

- 开盘形态。
- 日内路径。
- 高低价格区间。
- 个性化执行胜率。
- 模型稳定性和解释质量。

## 3. 五个子版本总览

| 子版本 | 主题 | 目标 | 输出 |
|---|---|---|---|
| v4.1 | 数据可信度与样本扩容 | 让训练数据稳定、完整、可追溯 | 数据质量面板、样本健康分、自动采样计划 |
| v4.2 | 开盘形态与日内路径 | 从“涨不涨”升级到“怎么走” | 开盘标签、路径标签、先收益/先止损判断 |
| v4.3 | 高低区间与风险收益 | 预测明天可能涨到哪、跌到哪 | 振幅预测、价格区间、真实可成交区间 |
| v4.4 | 个性化交易校准 | 用真实交易记录修正系统建议 | 用户执行画像、个性化胜率、个性化降权 |
| v4.5 | 决策驾驶舱 | 把页面收敛成一屏可操作 | 今日决策页、持仓页、复盘页、模型健康页 |

## 4. v4.1 数据可信度与样本扩容

### 目标

把 v3.0 的 SQLite 数据库从“能存”升级为“可训练、可信任、可持续积累”。

### 宏观范围

- 建立数据健康分。
- 统计日线、分钟、板块、市场环境、标签覆盖率。
- 对固定持仓建立每日自动样本刷新检查。
- 对真实交易记录建立闭环率、字段完整率、可用样本率。
- 增加缺失原因分类：行情缺失、字段缺失、标签未到期、接口失败。
- 增加样本扩容建议：今天需要补哪些股票、哪些数据源缺口最大。

### 暂定验收

- 能一眼看到“当前数据能不能训练”。
- 能知道模型为什么只能输出基准概率。
- 能形成每日固定持仓和候选池的样本沉淀节奏。

## 5. v4.2 开盘形态与日内路径

### 目标

补齐示范系统里的“怎么走”。

### 宏观范围

- 建立开盘形态标签：
  - 高开强承接。
  - 高开低走。
  - 低开修复。
  - 平开震荡。
  - 集合竞价异常。
- 建立日内路径标签：
  - 先涨后跌。
  - 先跌后涨。
  - 冲高回落。
  - 探底回升。
  - 单边走强。
  - 单边走弱。
- 增强分钟事件序列：
  - 首次触达低吸区间。
  - 首次达到 +1%。
  - 首次达到 +2%。
  - 首次触发 -2%。
- 明确 `first_event` 的计算口径。

### 暂定验收

- 次日复盘能解释一只票是怎么走的。
- 先止损和先收益不再依赖日线高低价猜测。
- 固定持仓能积累稳定分钟路径样本。

## 6. v4.3 高低区间与风险收益

### 目标

补齐示范系统里的“跌到哪里、涨到哪里、风险是否划算”。

### 宏观范围

- 预测次日振幅区间。
- 预测次日最高价区间。
- 预测次日最低价区间。
- 计算计划低吸区间与真实成交区间的重合度。
- 计算真实可执行风险收益比。
- 将概率收益风险比升级为价格区间收益风险比。
- 对“冲高回落但未成交”“先跌破止损再反弹”等情况单独标注。

### 暂定验收

- 单票决策能看到预估高低区间。
- 复盘报告能判断区间预测是否覆盖真实走势。
- 最终操作能解释“为什么风险收益不划算”。

## 7. v4.4 个性化交易校准

### 目标

把真实交易记录从“日志”升级为“个性化模型输入”。

### 宏观范围

- 建立用户交易画像：
  - 日内T胜率。
  - 隔日T胜率。
  - 平均到手利润。
  - 平均亏损。
  - 执行偏差。
  - 平均持有时长。
- 按股票、行业、市场环境、操作类型统计真实收益。
- 将用户真实交易结果反哺最终操作：
  - 用户擅长的类型可小幅加权。
  - 用户亏损集中的类型自动降权。
  - 未闭环交易不参与模型标签，只参与执行提醒。
- 增加真实交易和系统理论验证的差异分析。

### 暂定验收

- 页面能看到“我的真实日内T/隔日T表现”。
- 最终操作能体现个性化风险提示。
- 同一只股票可区分“系统理论成功”和“我实际是否赚到钱”。

## 8. v4.5 决策驾驶舱

### 目标

把页面从多个工程 Tab 收敛为更接近实盘的一屏式工作台。

### 宏观范围

页面重组为四个主区：

- 今日决策：市场环境、最终操作、候选优先级。
- 固定持仓：五只持仓的买点、卖点、路径、个性化建议。
- 交易与复盘：真实交易记录、次日复盘、收益统计。
- 模型健康：样本质量、模型评分、概率是否可信。

交互原则：

- 默认只展示今天要看的 3-5 个核心判断。
- 工程报告全部折叠到二级入口。
- 概率、规则、风控冲突时，直接给出冲突解释。
- 模型不可信时，页面直接降级提示。

### 暂定验收

- 打开页面一屏内能知道今天是否适合交易。
- 固定持仓能单独刷新并得到明确处理建议。
- 模型训练和预测不再让用户感到分散。
- 页面可以清楚展示“为什么今天不做”。

## 9. v4.0 不做范围

v4.0 先不做：

- 自动下单。
- 复杂深度学习。
- 多人协作后台。
- 移动端 App。
- 高频交易。

这些能力会显著提高风险和复杂度，当前个人本地决策系统不需要急着做。

## 10. 推荐节奏

每个子版本都按这个顺序做：

```text
宏观需求确认 -> 详细需求文档 -> 字段/表结构设计 -> 开发 -> 测试 -> 页面验收 -> 文档同步 -> commit
```

v4.0 的核心原则：

- 先提高数据可信度，再提高模型复杂度。
- 先做可解释路径，再做更复杂预测。
- 先让真实交易记录产生价值，再谈个性化模型。
- 先让页面更像实盘工作台，再继续扩功能。
