# 后台自动刷新开发计划

## 图谱关系

上游：[13-后台自动刷新需求](../03-需求文档/13-后台自动刷新需求.md)
下游：代码提交 `feat: add scheduled background refresh`

## 开发范围

1. 新增 `scheduled_refresh.py`
   - 定义 09:39、14:00、14:30、15:00 四个自动刷新点。
   - 执行 `main.py` 现有命令，复用主流程。
   - 写入状态 JSON 和日志。
   - 使用文件锁避免重复后台进程。
2. 修改 `scripts/start_streamlit_app.sh`
   - 启动 Streamlit 前拉起后台调度器。
3. 修改 `app.py`
   - 页面顶部展示后台刷新计划和最近运行状态。
4. 新增 `tests/test_scheduled_refresh.py`
   - 覆盖时间点、同日不重复、周末跳过。

## 验证方式

1. `python -m py_compile scheduled_refresh.py app.py`
2. `python -m unittest discover -s tests -p 'test_scheduled_refresh.py'`
3. `python scheduled_refresh.py --status`
4. Streamlit AppTest 启动页面无异常。

## 提交边界

只提交调度器、启动脚本、页面状态展示、测试和知识库文档；不提交自动刷新产生的行情缓存、SQLite、`output/` 运行结果。
