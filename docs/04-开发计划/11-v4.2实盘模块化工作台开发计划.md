## 1. 开发目标

把现有 Streamlit Tab 改成更接近实盘的模块化工作台，减少跳来跳去和重复表格。

## 2. 页面结构

- 左侧一级菜单：今日决策、固定持仓、单票决策、交易记录、模型与数据、复盘报表、系统设置。
- 二级菜单按模块展开。
- 右侧主区域只展示当前模块。

## 3. 展示规则

- 每个模块顶部放 3-5 个关键结论。
- 表格列统一排序：操作结论、股票、价格、风险、理由、辅助指标。
- 原始报告放折叠区。
- 版本号进入页脚或系统信息，不放在页面标题。

## 4. 技术任务

- 拆分 `app.py` 中页面渲染函数。
- 新增 `ui/` 目录或轻量模块，按业务页管理渲染逻辑。
- 抽出统一表格列排序函数。
- 保留旧 Tab 的兼容入口一个版本，避免一次性迁移风险。

## 5. 验证任务

- 本地运行 `streamlit run app.py`。
- 检查桌面宽屏和手机推送链接阅读效果。
- 确认固定持仓、候选池、交易记录互不混淆。

## 6. 提交边界

不改模型算法，不改数据口径；只重组页面和表格展示。
