## 开发范围

1. 修改固定持仓清单为大为股份、京东方A、华友钴业、捷捷微电。
2. 新增 `opening_levels.py`，计算固定持仓开盘支撑压力与T区间。
3. 增加 `main.py opening-levels` 命令。
4. 在页面新增“开盘T区间”Tab，放在“明日计划”之前。
5. 页面支持输入股票名称或代码做单票计算。
6. 接入 DeepSeek 作为 AI 辅助解释，不影响基础算法输出。
7. 自动刷新任务加入 `opening-levels`。
8. 增加单元测试覆盖核心区间计算。
9. 小修版本：09:25 增加集合竞价刷新；页面操作条改为固定持仓刷新、单票输入、单票计算同一行。

## 验证方式

1. `python -m py_compile opening_levels.py app.py main.py scheduled_refresh.py`
2. `python -m unittest discover -s tests -p 'test_opening_levels.py'`
3. `python main.py opening-levels --stock-code 002213`
4. 打开页面确认新增 Tab 能看到结果。
