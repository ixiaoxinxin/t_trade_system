# A股隔日T选股系统日常操作工作流

这篇文档只讲真实使用，不讲代码。

现在页面分成六个一级 Tab：

- 明日计划：收盘后看明天关注哪几只。
- 固定持仓：单独管理融捷股份、云天化、大为股份、神火股份、天齐锂业。
- 交易记录：随手记录真实日内T/隔日T，并自动计算手续费和到手利润。
- 午盘验证：11:20 后看上午结构和下午建议。
- 模型训练：保存训练数据后，训练 v2.6 方向模型并查看评估报告。
- 模型预测：生成次日上涨概率和方向置信度排序。

最重要的一句话：

> 收盘生成明日计划，盘中看固定持仓和午盘，真实买卖记到交易记录，收盘后保存训练数据，最后训练模型并生成预测。

## 1. 日常按钮怎么用

### 生成明日计划

收盘后点。

它会自动跑完：

1. 市场环境。
2. 候选扫描。
3. 尾盘确认。
4. 交易计划。

点完以后去「明日计划」看 A/B 候选。

### 更新卖点信号

有持仓时点。

它不是选新票的，是判断手里的票要继续拿、减仓、止盈还是止损。

### 午盘验证

11:20 以后点。

用来看昨天计划里的票上午走得怎么样，下午还值不值得盯。

### 次日复盘

第二天收盘后点。

它验证昨天计划是否触达低吸区间、是否到 +1% / +2%、是否触发 -2% 止损。

### 保存训练数据

次日复盘后点。

它把候选、计划、验证、真实交易记录、行情缓存沉淀到 SQLite，给后续模型训练用。

### 高级工具

平时不用频繁点。

- 单独刷新市场环境：只想看大盘状态时使用。
- 刷新固定持仓行情：单独刷新融捷股份、云天化、大为股份、神火股份、天齐锂业的日线和分钟数据。
- 刷新持仓买卖点：只刷新五只固定持仓的买点区间、买点状态和卖点信号。
- 迁移数据库：页面数据没刷新，或手动改了 output 文件后使用。

## 2. 六个 Tab 怎么看

### 明日计划

这里看明天要关注什么。

你主要看：

- 市场环境：今天适不适合隔夜。
- A/B 候选：明天优先盯哪些票。
- 模型概率：次日上涨概率和方向置信度。
- 次日验证：昨天计划的结果。

真实操作顺序：

```text
先看市场 -> 看 A/B 候选 -> 决定明天盯 1-3 只
```

### 固定持仓

这里专门处理你手里已有的五只票。

你主要看：

- 买点区间：今天有没有低吸条件。
- 买点状态：是否已经接近可操作区。
- 卖点信号：是否减仓、止盈、止损或继续观察。
- 午盘/次日状态：这几只票上午和次日表现如何。
- 模型概率：上涨概率是否支持继续拿。

常用按钮：

- 刷新固定持仓行情。
- 刷新持仓买卖点。
- 更新全部卖点信号。

### 交易记录

这里记录真实执行，不记录想法。

只在你真的买卖后填写：

- 日内T或隔日T。
- 股票名称和代码。
- 买入价、卖出价、数量。
- 是否按计划执行。
- 备注里写关键原因。

卖出价填了就是已闭环，系统会按招行证券万2.5、单笔最低5元计算手续费、到手利润和收益率。

### 午盘验证

这里中午看。

11:20 后点「午盘验证」，重点看：

- 午盘涨幅。
- 上午结构标签。
- 下午操作建议。
- 固定持仓是否需要处理。

### 复盘验证

复盘验证现在不再是独立 Tab，系统次日验证放在「明日计划」下方，真实复盘放在「交易记录」。

它分两类：

- 系统次日验证：系统昨天的计划理论上有没有成功。
- 真实交易复盘：你实际有没有买卖、有没有赚到钱、是否按计划执行。

这两个不要混在一起。

系统验证回答：

```text
这套规则昨天判断得对不对？
```

交易记录回答：

```text
我真实执行后赚没赚到钱？
```

### 模型训练

这里回答：

```text
我的数据够不够训练？训练出来的模型表现怎么样？
```

先点「保存训练数据」，再点「训练方向模型」。重点看样本数、标签数、评估报告。

### 模型预测

这里回答：

```text
明天哪些候选的上涨概率更高？
```

点「生成模型预测」后，看次日上涨概率排序。它只做辅助排序，不替代规则等级。

以后个性化模型要同时看这两件事。

## 3. 最贴近真实操作的一天

### 盘前或上午

打开「明日计划」和「固定持仓」。

先看市场环境。

如果是情绪冰点、系统风险、是否隔夜为否，就降低预期。可以观察，但不要强行做隔夜。

### 盘中有交易

直接在「交易记录」里填真实买卖。

只要先买了但还没卖，卖出价可以先空着，状态就是未闭环。

如果盘中涨起来，去「固定持仓」点「更新全部卖点信号」，看系统建议是继续拿、减仓、止盈还是止损。

### 中午

11:20 以后进入「午盘验证」，点「刷新午盘验证」。

它主要帮你判断上午结构：

- 上午强，下午可以继续观察。
- 上午冲高回落，下午要警惕。
- 上午完全不符合预期，可以降低关注。

### 收盘后

点「生成明日计划」。

然后进入「明日计划」，只看 A/B 候选和交易计划。

### 第二天收盘后

点「次日复盘」。

然后在「明日计划」下方看系统计划是否有效。

如果你当天做了真实交易，把「交易记录」补完整：卖出价、数量、备注。

最后点「保存训练数据」。

如果当天数据已经沉淀：

1. 进入「模型训练」，点「训练方向模型」。
2. 进入「模型预测」，点「生成模型预测」。
3. 回到「明日计划」或「固定持仓」看次日上涨概率。

## 4. 推荐固定节奏

### 每天必做

1. 收盘后点「生成明日计划」。
2. 第二天收盘后点「次日复盘」。
3. 有真实交易就填「交易记录」。
4. 次日复盘后点「保存训练数据」。
5. 数据更新后点「训练方向模型」和「生成模型预测」。

### 盘中按需做

- 有持仓：点「更新卖点信号」。
- 中午想看上午结构：点「午盘验证」。
- 固定持仓行情缺失：点「刷新固定持仓行情」。
- 只想看持仓买卖点：点「刷新持仓买卖点」。

### 每周做一次

- 看「明日计划」下方的系统验证结果。
- 看「交易记录」里的真实交易记录。
- 在「模型训练」看标签覆盖率和评估报告。
- 在「模型预测」看概率排序是否稳定。

## 5. 最简单的使用口诀

一句话版本：

> 收盘选明天，盘中管卖点，交易随手记，次日做复盘，最后进数据集。

按钮顺序版本：

```text
生成明日计划 -> 明日计划
有持仓 -> 固定持仓 -> 刷新持仓买卖点 / 更新卖点信号
有真实交易 -> 交易记录
中午 -> 午盘验证
第二天 -> 次日复盘 -> 明日计划看验证 -> 保存训练数据
有新训练数据 -> 模型训练 -> 模型预测
```

## 6. 容易混的地方

### 生成明日计划和保存训练数据不是一回事

生成明日计划是为了“明天看什么”。

保存训练数据是为了“把已经发生的预测和结果存起来，给以后训练模型用”。

### 更新卖点信号和次日复盘不是一回事

更新卖点信号是盘中决策辅助。

次日复盘是事后验证和打标签。

### 交易记录和系统验证不是一回事

系统验证记录的是“系统计划理论上有没有成功”。

交易记录记录的是“你实际有没有赚到钱”。

后面个性化模型要同时看这两件事。

### 人工复盘入口为什么删除

因为人工复盘很容易和交易记录重复。

以后真实复盘只从交易记录出发：你买了什么、卖了什么、赚亏多少、是否按计划执行。

## 7. 每天真正要盯的数字

首页中间那些数字可以这样理解：

- 市场环境：今天大背景。
- 是否隔夜：今天能不能做隔夜。
- A/B候选：明天值得认真看的票数量。
- 卖点信号：当前有多少持仓触发卖点判断。
- 午盘验证：有多少计划已经完成上午验证。
- 成功率：当前历史验证的大致成功率。
- 交易记录：你真实记录了多少笔交易。
- 已闭环：已经买卖闭环、可以用于真实复盘的交易数量。

如果只想快速判断今天要不要认真看盘，优先看：

```text
市场环境 -> 是否隔夜 -> A/B候选
```

如果已经有持仓，优先看：

```text
更新卖点信号 -> 交易记录 -> 午盘验证
```

如果在做系统迭代，优先看：

```text
次日复盘 -> 保存训练数据 -> 模型训练 -> 模型预测
```
