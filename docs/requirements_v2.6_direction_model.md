# v2.6 次日涨跌方向分类模型需求文档

## 1. 目标

v2.6 训练第一个机器学习方向模型，在现有规则评分之外，输出：

- 次日上涨概率。
- 方向置信度。
- 模型方向：上涨 / 下跌或震荡。
- 模型版本、训练区间和评估指标。

本版本只做“方向判断”，不替代规则等级，不直接自动改交易建议。

## 2. 前置能力

v2.6 依赖 v2.5 已完成的数据地基：

- SQLite 样本库：`data/dataset/trade_dataset.sqlite3`。
- 样本主表：`dataset_samples`。
- 特征快照表：`feature_snapshot`。
- 标签表：`label_snapshot`。
- 时间序列切分：`data/dataset/splits/latest.json`。
- 真实交易记录：`trade_records`。

### 3.1 展示规则

- 在卖点信号中固定置顶。
- 在午盘验证中固定置顶。
- 在次日复盘中固定置顶。
- 在页面「今日操作台」增加固定持仓监控区，一票一行展示买点、卖点、午盘、次日复盘和模型预测。
- 提供单独按钮刷新固定持仓买点和卖点，输出 `output/fixed_holdings_signals.csv`。

### 3.2 数据规则

- 固定持仓优先刷新日线和 1 分钟数据。
- 有行情时正常计算卖点、午盘结构和次日复盘。
- 行情为空时不隐藏股票，而是显示 `待刷新` 或 `行情待刷新`。
- `行情待刷新` 的次日复盘行不进入有效训练标签，避免污染模型。

## 4. 标签定义

v2.6 主标签为：

```text
direction_up_close = 次日收盘涨幅 > 0
```

含义：

- `1`：次日收盘价高于预测日参考价。
- `0`：次日收盘价不高于预测日参考价。

后续 v2.7 再训练 +1%、+2%、先止损等更贴近隔日T执行的概率模型。

## 5. 特征输入

模型读取 SQLite 的 `feature_snapshot`，优先使用已经沉淀的结构化特征：

- 日线收益率：1/3/5/20 日。
- 均线动量：MA5/10/20 缺口和斜率。
- 波动：ATR、历史波动率、近5日振幅。
- 成交：成交额、5日平均成交额、量比。
- K线：实体、上下影线、跳空。
- 分时：开盘强度、前15分钟收益和回撤、VWAP 偏离、路径标签。
- 市场环境：市场分层、风险等级。
- 板块：板块名称、板块状态、板块排名、广度、龙头强度。
- 规则结果：候选评分、尾盘评分、最终评分、隔夜等级。

## 6. 模型训练

### 6.1 算法

- 默认算法：LightGBM 二分类模型。
- 样本不足、标签单一或 LightGBM 不可用时，降级为正样本率基准概率，保证流程不中断。

### 6.2 切分

优先使用 `data/dataset/splits/latest.json`：

- train。
- validation。
- test。

如果切分文件不存在，则按 `predict_date` 顺序做 70% / 15% / 15% 切分，不随机打乱。

### 6.3 输出文件

- 模型文件：`data/models/direction_model_v2.6.joblib`。
- 特征列文件：`data/models/direction_model_v2.6_features.json`。
- 评估报告：`output/model_evaluation_v2.6.md`。
- 预测结果：`output/model_predictions_v2.6.csv`。

### 6.4 SQLite 表

新增：

- `model_training_runs`：记录模型版本、算法、训练区间、样本数、指标、特征列和模型路径。
- `model_prediction_results`：记录每只股票的次日上涨概率、方向置信度和模型方向。

## 7. 评估指标

必须输出：

- AUC。
- PR-AUC。
- 准确率。
- 分市场环境命中率。
- 分行业/板块命中率。

样本不足或单一标签时，对应指标显示为空，不伪造指标。

## 10. 验收标准

- 固定持仓五只股票在卖点信号、午盘验证、次日复盘中置顶展示。
- 固定持仓行情缺失时仍显示，不直接跳过。
- `python main.py holdings-refresh` 可刷新固定持仓日线与分钟数据。
- `python main.py holdings-signals` 可刷新固定持仓买点区间、买点状态和卖点信号。
- `python main.py model-train` 可生成模型文件和评估报告。
- `python main.py model-predict` 可生成全市场候选概率排序。
- `python main.py model-predict --stock-code 002466` 可输出单只股票预测结果。
- SQLite 中存在 `model_training_runs` 和 `model_prediction_results`。
- 页面「数据与模型」可以查看评估报告和概率排序。

## 11. 风险

- 当前样本量较少，方向模型可能弱于规则评分。
- 行情源缺分钟数据时，固定持仓只能显示待刷新，不产生有效分时特征。
- 样本不足时评估指标不稳定，不能据此直接放大仓位。
- 方向概率只回答“收盘是否上涨”，不回答是否达到 +1% / +2%，后者留给 v2.7。
