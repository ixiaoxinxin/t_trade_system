# 实盘页面简化需求文档

更新日期：2026-07-21

## 1. 背景

v3.0 已经打通规则、模型、板块、市场和最终操作，但实盘使用时发现页面仍偏工程化：

- 表格字段太多。
- 固定持仓和普通候选混在一起。
- 模型概率数值高度一致，不能用于排序。
- 操作解释太长，不适合盘中快速阅读。
- 交易记录录入不够顺手，利润未扣印花税。

本次改动目标是把页面改成“实盘能看懂、能快速记录、能明确区分用途”的简化版本。

## 2. 改动目标

- 明日计划只服务“明天怎么做”。
- 系统次日验证独立成 Tab，只服务复盘和训练数据。
- 固定持仓和普通候选分区展示。
- 所有决策表优先展示影响操作的列。
- 模型概率无区分度时自动降级，不作为主表排序依据。
- 操作解释改成固定短话术。
- 交易记录支持股票名称优先输入、价格文本输入、利润扣印花税。

## 3. 页面规则

### 3.1 表格列顺序

所有实盘表遵循：

```text
操作结论 -> 股票名称 -> 股票代码 -> 简短原因 -> 状态字段 -> 明细字段
```

主表原则上不超过 8-10 个核心列。

### 3.2 固定持仓和候选池分开

固定持仓回答：

```text
我手里的票现在怎么处理？
```

候选池回答：

```text
明天哪些票值得看？
```

两者不能只靠 1/0 字段区分，必须分区展示。

### 3.3 模型概率降级

当方向概率或收益目标概率基本一致时，页面显示：

```text
当前模型未形成有效区分，只作观察。
```

此时主表不展示大段概率字段，也不把模型概率作为强排序依据。

### 3.4 操作话术

固定持仓话术：

| 操作 | 页面短句 |
|---|---|
| 继续持有 | 继续持有：暂未触发卖点。 |
| 减仓 | 减仓：风险升高，先降仓位。 |
| 止盈 | 止盈：收益已到，先落袋。 |
| 清仓 | 清仓：卖点触发，先退出。 |
| 止损 | 止损：跌破风控，立即退出。 |

候选池话术：

| 操作 | 页面短句 |
|---|---|
| 优先低吸 | 优先低吸：只等计划买点。 |
| 小仓观察 | 小仓观察：可看，不追。 |
| 只观察 | 只观察：条件不够，先不买。 |
| 放弃 | 放弃：风险不划算。 |

系统验证话术：

| 验证结果 | 页面短句 |
|---|---|
| 计划有效 | 计划有效：给了买点，达到目标。 |
| 计划待优化 | 待优化：给了买点，但收益不足或风险先到。 |
| 未给买点 | 未给买点：计划没有成交机会。 |
| 数据不足 | 数据不足：今天不参与判断。 |

## 4. 交易记录改动

- 股票名称放在第一输入项。
- 系统根据股票名称反填股票代码。
- 股票代码仍可手动补充。
- 买入价、卖出价改为文本框。
- 数量保留数字输入。
- 利润计算增加卖出印花税。
- 印花税只在卖出侧计算，默认 0.05%。
- 费用字段拆分为买入佣金、卖出佣金、卖出印花税、费用合计。

## 5. 验收标准

- 页面存在独立「系统次日验证」Tab。
- 明日计划里固定持仓和候选池分开。
- A/B 候选表第一列是操作结论。
- 主表不再直接堆方向概率、收益目标概率、风险收益比。
- 模型概率一致时页面有降级提示。
- 交易记录可只输入股票名称并反填代码。
- 交易记录利润计算扣除印花税。
- 单元测试覆盖佣金、印花税和到手利润。
